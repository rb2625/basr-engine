# GSMA MENA Ignite Hackathon - SENTINEL

## Project: SENTINEL - Real-Time Urban Incident Detection with Network Intelligence

### Theme: Smart Cities, Urban Safety & Mega-Project Infrastructure

### Why We Win
- We have BASR (working AI pipeline, 623+ docs, Arabic/English/Arabizi)
- We have ArabiziKit (published Gulf Arabic library)
- We have anomaly detection (STL + z-score)
- We have a deployed dashboard + Telegram alerts
- 90% of teams are solo starting from scratch

### Solution
Smart city incident detection that VALIDATES reports using CAMARA APIs:
- Location Verification: Confirm reporter is at incident location
- Number Verification: Verify phone number is real
- Device Status: Check device is active
- Geofencing: Monitor specific zones
- AI Agent orchestrates everything intelligently

### APIs Used
| API | Purpose |
|-----|---------|
| Location Verification | Validate reporter location |
| Number Verification | Confirm phone legitimacy |
| Device Status | Filter inactive devices |
| Geofencing | Zone monitoring |
| QoS on Demand | Emergency connectivity |

### Tech Stack
- Backend: Python (extends BASR)
- AI Agent: Nokia NaC approved tools
- Frontend: Next.js (extends BASR dashboard)
- Database: Supabase
- Alerts: Telegram + Email
